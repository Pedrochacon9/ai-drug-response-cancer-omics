# Source code

This folder contains the adapted DeepTTC pipeline and auxiliary scripts used for preprocessing, training, inference and result analysis.

Some files are based on the original DeepTTC implementation and were adapted to work with the IMPROVE/CSA benchmark structure.

Main adapted scripts:
- `deepttc_preprocess_improve.py`: prepares IMPROVE/CSA data for DeepTTC.
- `deepttc_train_improve.py`: training pipeline.
- `deepttc_infer_improve.py`: inference and prediction pipeline.
- `process_results.py`: result processing and analysis.
- `benchmark.py`: benchmark execution utilities.
