# Documentation

This folder contains complementary documentation for the project.

The documentation includes notes about the dataset, model architecture, reproducible methodology, experimental design and results.

Main files:
- `architecture.md`: overview of the project architecture and data flow.
- `dataset_summary.md`: summary of the dataset structure.
- `reproducible_methodology.md`: steps followed to reproduce the experiments.
- `experimental_plan.md`: experimental design and evaluation strategy.
- `model_thesis_notes.md`: thesis notes about the model.
- `results_thesis_notes.md`: thesis notes about the results.
- `results_table.md`: summary table of experimental results.
- `meeting_summary.md`: short summary for project presentation or discussion.
- `project_log.md`: internal project log.

Some files may contain internal thesis notes originally drafted in Spanish.
